# My First Git Repository 🎉

Welcome to my first project on GitHub! This repository serves as a sandbox for me to learn and practice Git and version control fundamentals.

## 📝 Description
This project contains a simple HTML landing page. It is intentionally lightweight, allowing me to focus on learning how to:
*   Initialize a Git repository.
*   Stage and commit changes locally.
*   Push code to a remote GitHub repository.
*   Write basic Markdown for documentation.
